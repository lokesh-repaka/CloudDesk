# External Sharing and Guest Collaborator Access Control

CloudDesk workspaces provide granular security controls to prevent accidental exposure of proprietary files.

## Enabling External Sharing

If external sharing links are disabled:
1. Verify that your organization subscription tier is Pro or higher.
2. An organization admin must navigate to **Workspace Settings > Collaboration Policies**.
3. Toggle "Allow public link sharing" and specify the default expiration horizon (7, 30, or 90 days).
4. Save settings to activate external link generation immediately.
