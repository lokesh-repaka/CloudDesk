# Product Roadmap, Feature Requests, and Dark Mode Support

CloudDesk regularly reviews community feature requests to prioritize product improvements.

## Submitting Feature Requests

- Feature requests are categorized under `feature_request` and assigned `low` severity by policy rules.
- Suggestions are routed to the Product Management triage board.

## Dark Mode Theme Status

- Dark mode is currently supported natively across the CloudDesk Next.js frontend console.
- Toggle between Light, Dark, and System theme modes using the theme switcher located in the lower-left navigation sidebar or via user profile preferences.
